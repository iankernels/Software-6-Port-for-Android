# Software 6 Port for Android by Dead Line Studio.
*Original Software 6 was created by Just Developer's Ltd., in 2025.*
- This port features a type of graphics called 2.5D raycasting, which many games from the '90s on the MS-DOS platform used to create the illusion of 3D graphics, and we're creating something similar for Android. In 2025, Ian Kernels—that is, me—tried to create a game in this genre for all PC platforms, but then I halted development. Now I’ve started trying to create it again, but this time for all Android phones.
- **Key Features:**
- There are 64x64 textures, weapons and their sprites, graphics settings, FPS and minimap options, as well as a HUD with a joystick and buttons for selecting weapons, interacting with interactive objects (currently doors), and firing.
- **Controls:**
- Use the joystick to move the player, swipe the screen to adjust the player's view, press the USE button to interact with interactive objects, press the FIRE button to fire a weapon, and use the weapon selection buttons to choose a weapon - that much is obvious.
